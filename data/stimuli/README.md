# Stimulus sets

One CSV per task, regenerated by `python scripts/export_stimuli.py` (or `make stimuli`).
`manifest.csv` lists every file with its stimulus and category counts.

## Columns

| column | meaning |
|---|---|
| `stimulus_id` | row number, 1-based |
| `pc_*` | the binary input vector: one column per pitch class, 1 if that pitch class is present in the stimulus and 0 otherwise. Iranian tasks have 17 such columns (`pc_c` … `pc_b`), Western tasks 12. |
| `target_category` | integer class index used during training |
| `target_label` | the human-readable category name (interval name for interval tasks; interval signature in cents for Dang tasks) |
| `pitch_classes` | the pitch-class content of the stimulus, written out, for inspection |

## Example

From `iranian_interval_separate.csv`:

```
stimulus_id  pitch_classes  target_label
          2  c+dflat        baqieh
          3  c+dkoron       mojanab
          4  c+d            tanini
```

From `iranian_dang1_all36.csv` (a Dang is four pitch classes spanning a perfect fourth;
the label is the sequence of its three successive intervals in cents):

```
stimulus_id  pitch_classes      target_label
          1  c+dflat+dkoron+f   100-50-350
          2  c+dflat+d+f        100-100-300
```

## Note on the interval tasks

A stimulus is an unordered set of pitch classes, so the input for the pair {a, b} does not
encode which note came first. Interval labels are therefore assigned in one fixed direction
(ascending from the lower-indexed pitch class), which makes the label a deterministic
function of the input. The networks classify pitch-class sets, not directed melodic motions.
