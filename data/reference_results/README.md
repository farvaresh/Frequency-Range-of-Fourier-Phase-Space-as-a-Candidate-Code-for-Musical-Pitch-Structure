# Sample results & data dictionary

This folder contains reference outputs from the **full** run (25 networks per task; 6,900
hidden units across 275 networks), so readers can compare their own runs against the
numbers reported in the paper. All files are regenerated by:

```bash
python run_config.py full
python -m iranian_anns.analyze_results results_full/unit_fits.csv --out results_full/report
```

---

## `unit_fits.csv` — the raw per-unit results

One row per hidden unit. This is the primary output; every table below is derived from it.
(The copy here contains the columns needed to reproduce the analysis; a full run also
stores per-unit `best_R`, `best_phase`, `concentration`, and baseline columns.)

| column | meaning |
|---|---|
| `task` | task identifier (e.g. `iran_dang4_diss12`, `west_interval_separate`) |
| `system` | `Iranian-17` or `Western-12` |
| `control` | `none` (real task), `label_shuffled`, or `input_shuffled` |
| `best_freq` | best-fitting Fourier phase-space frequency (1..12 Iranian, 1..6 Western) |
| `null_p` | permutation-null p-value for this unit's best fit |

## `frequency_range.csv` — recruited frequency range (paper §Results, Fig. 5)

| column | meaning |
|---|---|
| `system`, `basis` | system and phase-space basis (`dft` = lattice DFT) |
| `n_sig`, `n_total`, `frac_sig` | FDR-significant units, total units, and their ratio |
| `min_freq`, `max_freq`, `nyquist` | recruited range and the lattice Nyquist ceiling |
| `reaches_nyquist` | whether the system recruits up to its ceiling |
| `mean_R` | mean best-fit correlation among significant units |
| `freqs_used` | the distinct frequencies recruited |

## `concentration.csv` — spectral concentration (A1)

| column | meaning |
|---|---|
| `mean_concentration`, `median_concentration` | share of spectral power in the best frequency |
| `mean_best_R` | mean best-fit correlation |
| `n_sig` | number of FDR-significant units |

Note: concentration is compared to a *per-system chance baseline* (Iranian ≈ 0.23,
Western ≈ 0.40), not across systems, because the number of candidate frequencies differs
(12 vs 6). Both systems sit well above chance.

## `high_freq_band.csv` — the non-mechanical core (A3)

| column | meaning |
|---|---|
| `n_sig`, `n_in_7_12`, `frac_in_7_12` | significant units, and how many/what fraction fall in the 7–12 band |
| `western_ceiling` | 6 — frequencies 7–12 are impossible for the 12-tone system |
| `note` | interpretation flag |

## `control_descriptive.csv` / `control_model.csv` — task-driven controls

`control_descriptive` gives mean fit and significant fraction per control condition.
`control_model` gives the decisive network-level paired contrast:

| column | meaning |
|---|---|
| `n_networks` | networks per system |
| `mean_logitR_real`, `mean_logitR_labelnull` | mean logit-R on real vs. label-shuffled tasks |
| `mean_diff` | real minus label-null (large positive = task-driven) |
| `wilcoxon_p` | paired Wilcoxon p-value |

## `baselines.csv` — Fourier vs. non-Fourier

| column | meaning |
|---|---|
| `comparison` | `best_R vs pitch_height_r` or `best_R vs random_r_p95` |
| `mean_fourier`, `mean_ref` | mean Fourier fit vs. baseline |
| `wilcoxon_p` | paired Wilcoxon p-value |

## `cardinality_descriptive.csv` / `cardinality_test.csv` — cardinality

Descriptive table (max/normalised frequency per system) and the network-level
Mann–Whitney test of normalised best frequency between systems.

## `system_basis_model.csv` — overall fit-strength comparison

Network-level Mann–Whitney comparing mean logit-R between the two systems.

## `results_report.md`

The full narrative report assembling all of the above with interpretive notes — the best
single file to read first.
